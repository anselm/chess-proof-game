PROOF GAME — how could this position have happened?

Set up any position and this tries to play a legal game from the opening array to it, with both players cooperating. It also audits the position for outright impossibility — a useful check on puzzle diagrams, which are sometimes unreachable.

Shortest-proof-game search is exact but only reaches ~8 moves; deeper positions get a constructive game that is legal but not minimal. Positions needing dozens of captures are beyond it — those are the domain of dedicated solvers (Euclide, Natch, Jacobi).
Engine, audit and search all run in your browser.
